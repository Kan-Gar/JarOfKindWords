# Баночка хороших слов

Статический цифровой подарок: уютная ночная сцена, стеклянная баночка и 158 писем: 150 записок пяти категорий, 6 очень редких намёков и 2 финальных признания. Без регистрации, сервера, ключей API и платных сервисов.

## Запуск

Нужен Node.js 22.12+ (проверено на 24.22.1), npm и современный браузер.

```bash
npm ci
npm run dev
```

В новом проекте также работает `npm install`; для воспроизводимой установки используйте `npm ci` с сохранённым `package-lock.json`. Если домашний каталог недоступен для записи в облачной среде:

```bash
npm ci --cache /workspace/.cache/npm --no-audit --no-fund
```

```bash
npm run build    # TypeScript и production-сборка в dist/
npm run preview  # локальная проверка production-сборки
npm test         # 17 тестов данных, выбора записок и сохранения
npm run test:e2e # 12 браузерных сценариев Chromium; запускает dev-сервер
```

Для браузерных тестов по умолчанию нужен `/usr/bin/chromium`. Другой установленный Chromium можно передать через `CHROMIUM_PATH=/path/to/chromium npm run test:e2e`. Браузерные тесты не устанавливают браузер автоматически. В текущей облачной среде он уже доступен. Порт тестового сервера — 5173; существующий dev-сервер на этом порту переиспользуется.

## Возможности

- Первый визит с приветствием; повторный просмотр из настроек.
- Авторская пиксельная сцена PixiJS: многослойное стекло, крышка, ленточка с сердечком, бумажки, луна, книги, лаванда и свеча.
- GSAP-последовательность: сжатие и встряхивание, поднятие крышки, полёт по кривой Безье, разворачивание бумажной карточки. Последующие открытия быстрее.
- Пять категорий, случайный режим и выбор настроения. Редкие записки получают золотую рамку и более яркое свечение.
- Избранное с просмотром, открытием и удалением через сердечко.
- Версионированное сохранение, история прочитанного, прогресс циклов и настройки.
- Синтезированные Web Audio API звуки стекла, шелеста и волшебства. По умолчанию включены; воспроизведение начинается после первого нажатия. Выключение сохраняется.
- DOM-интерфейс с клавиатурным управлением, native dialog, фокусом, доступными подписями, прокруткой длинных сообщений.
- Safe area, `dvh` и резервные размеры, ограничение DPR до 2, сокращение частиц при медленных кадрах, остановка сцены при скрытии вкладки, системное уменьшение движения.
- Упрощённая CSS-баночка, если WebGL недоступен. Избранное и записки работают без графического ускорения, звука и доступного localStorage.

## Как выбираются записки

`NoteManager` использует взвешенный выбор **без возвращения**. Вес = `weight` × коэффициент редкости (common: 1, rare: 0.35, special: 0.12, confession: 0.006). Это относительные веса, а не фиксированный процент: вероятность меняется по мере опустошения цикла. Даже особенная записка обязательно встретится за полный цикл.

У случайного режима и каждой категории независимая очередь. Завершение категории обновляет только её очередь. Последняя показанная записка исключается, если есть другая доступная. При переключении между независимыми режимами уже прочитанная в другом режиме записка может встретиться снова — ограничение повторов действует внутри выбранного цикла.

Сохранение `kind-words-jar.v1` содержит только идентификаторы избранного и историю, а не копии текстов. Неизвестные идентификаторы удаляются при загрузке, новые записки добавляются в очередь. Повреждённый JSON сбрасывается к безопасному начальному состоянию, неизвестная версия не интерпретируется. Если запись запрещена, приложение продолжает работать в памяти.

## Добавить или изменить сообщения

Редактируйте `src/data/notes.json`. Пример объекта:

```json
{
  "id": "support_021",
  "category": "support",
  "text": "Можно немного выдохнуть. Ты не обязана всё успеть прямо сейчас.",
  "rarity": "common",
  "weight": 1
}
```

Категории: `support`, `compliment`, `humor`, `warmth`, `special`. Редкость: `common`, `rare`, `special`, `confession`. ID должен быть уникальным и оставаться стабильным при исправлении текста; `weight` — положительным числом. Тексты вставляются через `textContent`, не как HTML. Для сотен новых записок менять алгоритм не нужно. После изменения количества обновите ожидаемые числа в тестах набора данных; счётчик интерфейса вычисляется автоматически. Затем выполните `npm test` и `npm run build`.

Персонализировать подарок можно в текстах JSON и приветствии в `src/components/UIManager.ts`. Начальные записки не содержат выдуманных личных воспоминаний, имён и обязательного романтического подтекста.
